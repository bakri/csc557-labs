    Activity 2 – Screen Rotation

    Rotating the screen is a configuration change. Android destroys the activity and creates a new one, so any value kept in the activity is lost unless you save it.

    1. Continue with the Lifecycle project. On the emulator, turn on Auto-rotate: swipe down from the top of the screen twice and tap Auto-rotate.
    2. Run the app and rotate the device with the rotate buttons on the emulator toolbar. In Logcat you will see the activity destroyed and created again: onPause() → onStop() → onDestroy() → onCreate() → onStart() → onResume().
    3. Open res/layout/activity_main.xml in Code view. Replace the “Hello World!” TextView with a counter TextView and a Count button:
      res/layout/activity_main.xml (inside the ConstraintLayout)
          <TextView        android:id="@+id/tvCount"        android:layout_width="wrap_content"        android:layout_height="wrap_content"        android:text="0"        android:textSize="48sp"        app:layout_constraintBottom_toBottomOf="parent"        app:layout_constraintEnd_toEndOf="parent"        app:layout_constraintStart_toStartOf="parent"        app:layout_constraintTop_toTopOf="parent" />​    <Button        android:id="@+id/btnCount"        android:layout_width="wrap_content"        android:layout_height="wrap_content"        android:layout_marginTop="24dp"        android:onClick="countBtnClicked"        android:text="Count"        app:layout_constraintEnd_toEndOf="parent"        app:layout_constraintStart_toStartOf="parent"        app:layout_constraintTop_toBottomOf="@id/tvCount" />

      android:onClick="countBtnClicked" tells Android to call the method countBtnClicked(View view) in MainActivity when the button is clicked.

    4. In MainActivity.java, add two imports, two variables, one line at the end of onCreate(), and the countBtnClicked() method:
      java/com/example/lifecycle/MainActivity.java
      import android.view.View;import android.widget.TextView;​public class MainActivity extends AppCompatActivity {​    String label = "MyApp : ";    int count = 0;       // number of clicks    TextView tvCount;    // shows the count​    @Override    protected void onCreate(Bundle savedInstanceState) {        // ... template code and Log.d stay ...        tvCount = findViewById(R.id.tvCount);    }​    /** onClick() action handler for the Count button */    public void countBtnClicked(View view) {        count++;        tvCount.setText(String.valueOf(count));    }​    // ... the lifecycle methods from Activity 1 stay ...}
    5. Run the app and click Count five times. Now rotate the device. The counter goes back to 0, because the new activity object starts again with count = 0.
    6. To keep the value, save it in onSaveInstanceState() before the activity is destroyed, and read it back in onCreate(). Add this method to MainActivity, and the if block at the end of onCreate():
      java/com/example/lifecycle/MainActivity.java
          @Override    protected void onCreate(Bundle savedInstanceState) {        // ... template code and Log.d stay ...        tvCount = findViewById(R.id.tvCount);​        // restore the saved value after a rotation        // (savedInstanceState is null when the app starts for the first time)        if (savedInstanceState != null) {            count = savedInstanceState.getInt("count");            tvCount.setText(String.valueOf(count));        }    }​    /** Called before the activity may be destroyed, to save its state. */    @Override    protected void onSaveInstanceState(Bundle outState) {        super.onSaveInstanceState(outState);        outState.putInt("count", count);        Log.d(label, "The onSaveInstanceState() event");    }
    7. Run the app again, click Count five times and rotate the device. This time the value is kept.

    Activity 3a – Start an Activity using Intent

    You will build an app with two screens. Clicking Register in MainActivity opens RegisterSuccessActivity.

    1. Create a new project named Register (Empty Views Activity, Java).
    2. Replace the whole of res/layout/activity_main.xml with this layout: a title and a Register button.
      res/layout/activity_main.xml
      <?xml version="1.0" encoding="utf-8"?><androidx.constraintlayout.widget.ConstraintLayout    xmlns:android="http://schemas.android.com/apk/res/android"    xmlns:app="http://schemas.android.com/apk/res-auto"    xmlns:tools="http://schemas.android.com/tools"    android:id="@+id/main"    android:layout_width="match_parent"    android:layout_height="match_parent"    tools:context=".MainActivity">​    <TextView        android:id="@+id/tvTitle"        android:layout_width="wrap_content"        android:layout_height="wrap_content"        android:text="Student Registration"        android:textSize="24sp"        android:textStyle="bold"        app:layout_constraintBottom_toTopOf="@id/btnRegister"        app:layout_constraintEnd_toEndOf="parent"        app:layout_constraintStart_toStartOf="parent"        app:layout_constraintTop_toTopOf="parent"        app:layout_constraintVertical_chainStyle="packed" />​    <Button        android:id="@+id/btnRegister"        android:layout_width="wrap_content"        android:layout_height="wrap_content"        android:layout_marginTop="32dp"        android:onClick="registerBtnClicked"        android:text="Register"        app:layout_constraintBottom_toBottomOf="parent"        app:layout_constraintEnd_toEndOf="parent"        app:layout_constraintStart_toStartOf="parent"        app:layout_constraintTop_toBottomOf="@id/tvTitle" />​</androidx.constraintlayout.widget.ConstraintLayout>

      When the user clicks Register, the method registerBtnClicked() in MainActivity is called (set by android:onClick).

    3. Add the second activity: File › New › Activity › Empty Views Activity. Name it RegisterSuccessActivity and leave Launcher Activity unticked. Android Studio creates RegisterSuccessActivity.java, activity_register_success.xml, and adds the activity to AndroidManifest.xml:
      manifests/AndroidManifest.xml
      <activity    android:name=".RegisterSuccessActivity"    android:exported="false" />
    4. Open res/layout/activityregistersuccess.xml. Add one TextView inside the ConstraintLayout (keep the root and its @+id/main):
      res/layout/activity_register_success.xml (inside the ConstraintLayout)
          <TextView        android:id="@+id/tvSuccess"        android:layout_width="wrap_content"        android:layout_height="wrap_content"        android:text="Registration successful"        android:textSize="22sp"        app:layout_constraintBottom_toBottomOf="parent"        app:layout_constraintEnd_toEndOf="parent"        app:layout_constraintStart_toStartOf="parent"        app:layout_constraintTop_toTopOf="parent" />
    5. In MainActivity.java, add the registerBtnClicked() method. It creates an explicit Intent that names the activity to open, and starts it.
      java/com/example/register/MainActivity.java
      import android.content.Intent;import android.view.View;​public class MainActivity extends AppCompatActivity {​    // ... onCreate() from the template stays ...​    /**     * onClick() action handler for Register button     * @param view     */    public void registerBtnClicked(View view) {        // Task 1: Start RegisterSuccessActivity Activity using Intent​        // create a new explicit intent to open RegisterSuccessActivity activity        Intent intentSuccess = new Intent(this, RegisterSuccessActivity.class);        // start the RegisterSuccessActivity activity        startActivity(intentSuccess);    }}
    6. Run the app and click Register. The second screen shows Registration successful (the first two screens in the picture above). Use the Back gesture to return to MainActivity.

    Activity 3b – Passing values to an Activity using putExtra()

    Now MainActivity sends a name and a gender to RegisterSuccessActivity, which greets the user. The values are hard-coded for now. Next week you will read them from a form instead.

    1. Edit registerBtnClicked() in MainActivity.java to put the values into the Intent before starting the activity:
      java/com/example/register/MainActivity.java
          public void registerBtnClicked(View view) {        // Task 1: Start RegisterSuccessActivity Activity using Intent        Intent intentSuccess = new Intent(this, RegisterSuccessActivity.class);​        // Task 2: pass values (name and gender) to RegisterSuccessActivity using putExtra        // the values are hard-coded for now (form handling is next week)        String name = "Sally";        String gender = "Female";​        // set data to be sent to RegisterSuccessActivity activity        intentSuccess.putExtra("name", name);        intentSuccess.putExtra("gender", gender);​        // start the RegisterSuccessActivity activity        startActivity(intentSuccess);    }
    2. In RegisterSuccessActivity.java, read the values from the Intent at the end of onCreate() and show them in the label:
      java/com/example/register/RegisterSuccessActivity.java
      import android.content.Intent;import android.widget.TextView;​public class RegisterSuccessActivity extends AppCompatActivity {​    @Override    protected void onCreate(Bundle savedInstanceState) {        super.onCreate(savedInstanceState);        EdgeToEdge.enable(this);        setContentView(R.layout.activity_register_success);        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);            return insets;        });​        // Task 3: read data passed from MainActivity and display them inside the label        // get parameters from intent        Intent intent = getIntent();        String name = intent.getStringExtra("name");        String gender = intent.getStringExtra("gender");​        // update the text inside the success label        TextView tvSuccess = findViewById(R.id.tvSuccess);        if (gender.equals("Male"))            tvSuccess.setText("Hello Mr. " + name);        else            tvSuccess.setText("Hello Ms. " + name);    }}

      The keys must match exactly: "name" in putExtra() and "name" in getStringExtra(). A wrong key gives null.

    3. Run the app and click Register. The second screen now shows Hello Ms. Sally (the third screen in the picture in Activity 3a). Change the values to "Ali" and "Male" and run again to check the other greeting.

    Activity 4 – Using Fragment

    A Fragment is part of a screen with its own layout and Java code, placed inside an Activity. MainActivity shows two buttons and a FrameLayout. Clicking First Fragment places FirstFragment in the FrameLayout; clicking Second Fragment replaces it with SecondFragment. Each Fragment has a TextView and a button that shows the Fragment’s name in a Toast.

    1. Create a new project named FragmentExample (Empty Views Activity, Java).
    2. Replace the whole of res/layout/activity_main.xml: two buttons and a FrameLayout that will hold the Fragments.
      res/layout/activity_main.xml
      <?xml version="1.0" encoding="utf-8"?><LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"    xmlns:tools="http://schemas.android.com/tools"    android:id="@+id/main"    android:layout_width="match_parent"    android:layout_height="match_parent"    android:orientation="vertical"    tools:context=".MainActivity">​    <Button        android:id="@+id/btnFirstFragment"        android:layout_width="match_parent"        android:layout_height="wrap_content"        android:layout_marginHorizontal="16dp"        android:onClick="btnFirstFragmentClicked"        android:text="First Fragment" />​    <Button        android:id="@+id/btnSecondFragment"        android:layout_width="match_parent"        android:layout_height="wrap_content"        android:layout_marginHorizontal="16dp"        android:onClick="btnSecondFragmentClicked"        android:text="Second Fragment" />​    <FrameLayout        android:id="@+id/frameLayout"        android:layout_width="match_parent"        android:layout_height="0dp"        android:layout_marginTop="8dp"        android:layout_weight="1" />​</LinearLayout>
    3. Create the layout of the first Fragment: right-click res › layout › New › Layout Resource File, name it fragment_first, root element LinearLayout. Replace its content with:
      res/layout/fragment_first.xml
      <?xml version="1.0" encoding="utf-8"?><LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"    android:layout_width="match_parent"    android:layout_height="match_parent"    android:background="#E8EAF6"    android:gravity="center"    android:orientation="vertical">​    <TextView        android:layout_width="wrap_content"        android:layout_height="wrap_content"        android:text="This is First Fragment"        android:textSize="20sp" />​    <Button        android:id="@+id/btnShowName"        android:layout_width="wrap_content"        android:layout_height="wrap_content"        android:layout_marginTop="24dp"        android:text="Show Name" />​</LinearLayout>
    4. Create the Java class of the first Fragment: right-click your package (under java) › New › Java Class, name it FirstFragment, and replace its content with the code below (keep your own package line).
      java/com/example/fragmentexample/FirstFragment.java
      package com.example.fragmentexample;​import android.os.Bundle;import android.view.View;import android.widget.Button;import android.widget.Toast;​import androidx.annotation.NonNull;import androidx.annotation.Nullable;import androidx.fragment.app.Fragment;​public class FirstFragment extends Fragment {​    public FirstFragment() {        super(R.layout.fragment_first);   // the layout of this Fragment    }​    // called after the layout is created: find views and set listeners here    @Override    public void onViewCreated(@NonNull View view, @Nullable Bundle savedInstanceState) {        super.onViewCreated(view, savedInstanceState);        Button btnShowName = view.findViewById(R.id.btnShowName);        btnShowName.setOnClickListener(v ->                Toast.makeText(getContext(), "First Fragment", Toast.LENGTH_SHORT).show());    }}

      A Fragment is not an Activity, so android:onClick in its layout would look for the method in MainActivity. That is why the Fragment sets its own click listener in onViewCreated().

    5. Create fragment_second.xml and SecondFragment.java the same way (or copy the two files and rename them). Change only these parts:
    FirstFragmentSecondFragment
    Layout in super(...)R.layout.fragment_firstR.layout.fragment_second
    Background#E8EAF6#E0F2F1
    TextView textThis is First FragmentThis is Second Fragment
    Toast textFirst FragmentSecond Fragment
    1. To place a Fragment into the FrameLayout, we get the FragmentManager, begin a FragmentTransaction, replace the FrameLayout content with the Fragment, and commit. Add both onClick handlers to MainActivity.java:
      java/com/example/fragmentexample/MainActivity.java
      import android.view.View;import androidx.fragment.app.FragmentManager;import androidx.fragment.app.FragmentTransaction;​public class MainActivity extends AppCompatActivity {​    // ... onCreate() from the template stays ...​    /** Handle onClick action on first button */    public void btnFirstFragmentClicked(View view) {        // load the first fragment into the FrameLayout (id = frameLayout)        FragmentManager fm = getSupportFragmentManager();      // create a FragmentManager        FragmentTransaction fragmentTransaction = fm.beginTransaction();   // begin        // replace whatever is in the FrameLayout with FirstFragment        fragmentTransaction.replace(R.id.frameLayout, new FirstFragment());        fragmentTransaction.commit();                          // save the changes    }​    /** Handle onClick action on second button */    public void btnSecondFragmentClicked(View view) {        FragmentManager fm = getSupportFragmentManager();        FragmentTransaction fragmentTransaction = fm.beginTransaction();        fragmentTransaction.replace(R.id.frameLayout, new SecondFragment());        fragmentTransaction.commit();    }}
    2. Run the app. Click First Fragment and Second Fragment and check that the Fragment changes. Click Show Name in each Fragment to see its Toast.

    Troubleshooting

    ProblemLikely cause and fix
    Build error: cannot find symbol ... mainThe root layout lost android:id="@+id/main". Add it back.
    Logcat shows nothingType MyApp in the filter box, and check the right device and app are selected at the top of Logcat.
    Rotation does nothingTurn on Auto-rotate in the emulator’s quick settings.
    App crashes on click: Could not find method ... for android:onClickThe method name in android:onClick must match a public void name(View view) method in that Activity.
    ActivityNotFoundExceptionRegisterSuccessActivity is not in AndroidManifest.xml. Create activities with File › New › Activity.
    Second screen shows Hello Ms. nullThe key in getStringExtra() does not match the key in putExtra().
    Age shows 0The age was sent as a String ("21") but read with getIntExtra(). Send an int.
    Nothing appears below the buttonsCheck fragmentTransaction.commit() is called and the FrameLayout has layout_weight="1".
